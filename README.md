# TaskFlow - Gerenciador de Tarefas via Console

O **TaskFlow** é uma aplicação console em .NET 10 para gerenciamento de tarefas (To-Do List), desenvolvida com foco em qualidade de código, cobertura de testes unitários com xUnit e histórico de commits estruturado com Conventional Commits.

## Como Executar o Projeto

### 1. Compilar a Solução
Para compilar a solução e verificar se não existem erros de sintaxe ou dependências:
```bash
dotnet build
```


### 2. Executar a Aplicação Console
Para iniciar o menu interativo no terminal:
```bash
dotnet run --project TaskFlow.Console
```

### 3. Executar a Suíte de Testes Unitários
Para rodar os testes automatizados do xUnit e validar as regras de negócio:
```bash
dotnet test
```
